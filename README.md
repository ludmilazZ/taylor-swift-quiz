# Quiz da Taylor Swift 🎵

Um jogo de quiz interativo e divertido sobre a Taylor Swift que você pode jogar diretamente no seu navegador! Teste seus conhecimentos sobre a música, vida e carreira da Taylor.

## 🎮 Como Jogar
1. Acesse o site através do GitHub Pages
2. Clique em "Começar Quiz" para iniciar
3. Responda cada pergunta selecionando uma das opções
4. Receba feedback imediato sobre suas respostas
5. Veja sua pontuação final ao terminar
6. Jogue novamente para melhorar sua pontuação!

## ✨ Funcionalidades
- 10 perguntas de múltipla escolha sobre a Taylor Swift
- Sistema de pontuação em tempo real
- Feedback imediato após cada resposta
- Interface bonita e responsiva
- Design inspirado na estética da Taylor Swift
- Totalmente em português brasileiro
- Jogue diretamente no navegador - sem necessidade de download!
