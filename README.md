# Taylor Swift Quiz Game 🎵

A fun, interactive quiz game about Taylor Swift that you can play directly in your browser! Test your knowledge about Taylor's music, life, and career.

## Features
- Multiple choice questions about Taylor Swift
- Score tracking
- Immediate feedback on answers
- Beautiful UI with Taylor Swift themed design
- Play directly in your browser - no download needed!

## How to Play
1. Simply visit the GitHub Pages site
2. Click "Start Quiz" to begin
3. Answer each question by selecting one of the options
4. Get your final score at the end
5. Play again to improve your score!

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
